## 核心觀念地圖

機械加工不是單純「用刀切材料」，而是以下系統的耦合問題：

```text
零件功能需求
  -> 幾何特徵與公差
  -> 製程選擇
  -> 機台與夾持
  -> 刀具材料與幾何
  -> 切削條件
  -> 切削力、熱、振動、磨耗
  -> 尺寸精度、表面完整性、成本
```

研究所層級要能回答的不只是「這是什麼機器」，而是：

- 為什麼這個加工法能形成該幾何？
- 哪些參數主導切削力、溫度、刀具壽命與表面粗糙度？
- 若提高產能，限制會先出現在刀具、機台功率、夾持剛性、排屑，還是品質規格？
- 設計者如何在功能、公差、成本與可製造性之間取捨？

## 16.1 機械加工與零件幾何

### 必備知識

- **創建 generating**：由刀具軌跡形成表面，適合用運動學、包絡面與座標轉換分析。
- **成形 forming**：由刀具輪廓直接決定工件輪廓，刀具磨耗會直接轉移到工件形狀誤差。
- **特徵導向製程規劃**：把零件分解為外圓、端面、孔、槽、平面、螺紋、輪廓等特徵，再對應車削、鑽孔、搪孔、銑削、拉削或鋸削。
- **基準 datum**：加工規劃要先決定設計基準、加工基準與量測基準是否一致；基準不一致會造成誤差累積。

### 原理

幾何形成可以用「刀具形狀」與「相對運動」兩軸分類：

| 類型 | 形狀來源 | 典型例子 | 主要誤差來源 |
|---|---|---|---|
| 創建 | 刀具路徑 | 車外圓、面銑平面 | 進給誤差、主軸跳動、軸向定位誤差 |
| 成形 | 刀具輪廓 | 成形刀、拉削、螺紋牙形 | 刀具輪廓誤差、磨耗、裝刀誤差 |
| 混合 | 刀具輪廓 + 路徑 | 車螺紋、輪廓銑削 | 插補誤差、刀具補償、刀具磨耗 |

## 16.2 車削及相關作業

### 必備公式

切削速度：

```text
V = pi D N / 1000
N = 1000 V / (pi D)
```

變數：

- `V`：切削速度，m/min
- `D`：工件直徑，mm
- `N`：主軸轉速，rev/min

車削進給速度：

```text
F = f N
```

- `F`：軸向進給速度，mm/min
- `f`：每轉進給，mm/rev

車削加工時間：

```text
T_m = L / (f N)
```

- `T_m`：加工時間，min
- `L`：有效切削長度，mm

車削材料移除率近似式：

```text
MRR = V f d
```

若 `V` 用 mm/min、`f` 用 mm/rev、`d` 用 mm，則 `MRR` 約為 mm^3/min。

外圓車削精確體積式：

```text
MRR = pi (D_o^2 - D_f^2) L / (4 T_m)
```

- `D_o`：原始直徑
- `D_f`：加工後直徑

理論車削粗糙度：

```text
R_a ≈ f^2 / (32 r_n)
R_t ≈ f^2 / (8 r_n)
```

- `R_a`：理論算術平均粗糙度
- `R_t`：理論最大高度粗糙度
- `r_n`：刀鼻半徑

### 專業原理

- **車削力方向**：切削力通常可分解為主切削力、進給力與徑向力；徑向力會造成工件撓曲，是長軸車削錐度誤差的重要來源。
- **刀尖半徑取捨**：刀鼻半徑變大可降低理論粗糙度，但會增加徑向力與顫振風險。
- **細長工件問題**：長徑比高的軸件需用尾座、中心架或跟刀架支撐，否則會因切削力造成彎曲。
- **搪孔穩定性**：搪孔桿長徑比越大，剛性越低；內孔加工常由顫振與排屑限制，而不是單純由功率限制。

## 16.3 鑽孔及相關作業

### 必備公式

鑽孔切削速度：

```text
V = pi D N / 1000
```

鑽孔進給速度：

```text
F = f N
```

鑽孔加工時間：

```text
T_m = L / (f N)
```

鑽孔材料移除率：

```text
MRR = (pi D^2 / 4) f N
```

鑽尖額外進刀量近似：

```text
A = 0.5 D tan(90° - theta / 2)
```

- `A`：鑽尖造成的額外進刀量
- `theta`：鑽尖角

### 專業原理

- **孔走偏**：鑽頭橫刃不具真正切削速度，會造成高推力與定心困難；中心鑽或點鑽可降低走偏。
- **深孔排屑**：孔越深，切屑與冷卻液越難到達切削區；深孔加工常需啄鑽、高壓內冷或槍鑽。
- **孔品質階層**：鑽孔負責建立孔，鉸孔改善尺寸與表面，搪孔改善位置、圓度與同軸度。
- **導夾具功能**：導套把孔位置精度轉移到治具上，適合大量重複孔加工。

## 16.4 銑削

### 必備公式

銑削切削速度：

```text
V = pi D N / 1000
```

工作台進給速度：

```text
F = f_z z N
```

- `f_z`：每齒進給，mm/tooth
- `z`：刀齒數

銑削材料移除率：

```text
MRR = w d F
```

- `w`：切削寬度，mm
- `d`：切削深度，mm

每齒進給反算：

```text
f_z = F / (z N)
```

### 專業原理

- **順銑 down milling**：切屑厚度由大到小，表面品質通常較好，但對機台背隙與夾持剛性敏感。
- **逆銑 up milling**：切屑厚度由小到大，較不會被背隙拉動，但初始摩擦較多，刀具磨耗與表面擦傷可能增加。
- **刀齒衝擊**：銑削是斷續切削，每一齒進出工件都造成熱與力的週期載荷。
- **切屑厚度控制**：每齒進給太小會造成摩擦與加工硬化；太大會造成崩刃、振動或主軸負載過高。
- **刀具跳動 runout**：多刃刀具若跳動過大，實際只有少數刀齒承擔切削，會降低刀具壽命與表面品質。

## 16.5 綜合加工機與車削中心

### 必備知識

- **一次裝夾 one setup** 是加工中心最大的價值之一，可降低基準轉換誤差與非切削時間。
- **ATC 自動換刀** 讓銑削、鑽孔、攻牙、倒角、鉸孔可在同一機台連續完成。
- **多軸定位** 可減少拆裝工件，但需要更嚴格的後處理、碰撞檢查與座標轉換。
- **銑車削中心** 特別適合軸類零件上同時存在外圓、端面、偏心孔、平面、槽與螺紋的工件。

### 專業原理

加工中心的效率不只看切削速度，還要看：

```text
總週期時間 = 切削時間 + 換刀時間 + 快速移動時間 + 上下料時間 + 量測/補正時間
```

改善生產率時，必須判斷瓶頸：

- 若切削時間占比高：優化刀具、切削條件與刀路。
- 若換刀與移動時間占比高：合併刀具、優化工序排序。
- 若上下料占比高：使用托盤、治具或自動化上下料。
- 若檢驗占比高：導入機上量測與統計製程管制。

## 16.6 其他機械加工作業

### 必備知識

- **刨削 shaping/planing**：單點刀具往復加工平面，效率低但有助於理解生成面。
- **拉削 broaching**：多齒刀具一次完成粗切到精切，刀具昂貴但量產效率高。
- **鋸削 sawing**：主要用於切斷與備料，切縫寬度會影響材料利用率。

### 專業原理

拉削每齒切深稱為齒升量。齒升量太大會使拉削力過高，太小則刀具過長、成本增加。

鋸削選齒距時需考慮：

- 工件厚度越薄，齒距通常要越細。
- 至少要有數個齒同時接觸工件，避免單齒負載過大。
- 切屑需能容納於齒槽，否則會堵屑、發熱與斷齒。

## 16.7 高速機械加工

### 必備公式

DN 比：

```text
DN = d_b N
```

- `d_b`：主軸軸承內徑，mm
- `N`：主軸最高轉速，rev/min

hp/rpm 比：

```text
hp/rpm = spindle horsepower / maximum rpm
```

### 專業原理

- 高速加工的重點是高轉速、高進給、低徑向吃刀、穩定刀路與高動態控制的整合。
- 高速銑削常用小切寬、高進給的刀路降低瞬間負載，讓切削熱更多由切屑帶走。
- CNC 預讀 look-ahead 能提前處理轉角、曲率與加減速，避免路徑過衝或速度劇烈波動。
- 高速加工中刀具與刀柄動平衡非常重要，否則離心力會造成振動、主軸負載與表面波紋。

## 16.8 公差與表面光潔度

### 必備公式

製程能力：

```text
C_p = (USL - LSL) / (6 sigma)
C_pk = min((USL - mu) / (3 sigma), (mu - LSL) / (3 sigma))
```

- `USL`：上規格界限
- `LSL`：下規格界限
- `mu`：製程平均
- `sigma`：製程標準差

公差堆疊最壞情況：

```text
T_total = T_1 + T_2 + ... + T_n
```

統計 RSS 公差堆疊：

```text
T_total = sqrt(T_1^2 + T_2^2 + ... + T_n^2)
```

Taylor 刀具壽命式：

```text
V T^n = C
```

- `V`：切削速度
- `T`：刀具壽命
- `n, C`：由刀具、工件材料與切削條件決定的常數

### 專業原理

- **理論粗糙度** 只考慮刀具幾何與進給；實際粗糙度還包含積屑瘤、撕裂、振動、刀具磨耗與材料非均質性。
- **公差不是越小越好**，而是要剛好滿足功能。過度收緊公差會增加加工、檢驗、重工與報廢成本。
- **表面完整性** 不只包含粗糙度，也包含殘留應力、加工硬化、微裂紋、白層與熱影響。
- **顫振 chatter** 是切削系統動態不穩定現象，會造成週期性波紋、噪音、刀具崩裂與尺寸不穩。

## 16.9 產品設計考量

### 必備設計原則

- 優先採用淨成形或接近淨成形，僅加工功能面。
- 使用標準孔徑、標準螺紋、標準刀具半徑與標準材料尺寸。
- 避免內尖角、深窄槽、底切、薄壁長懸伸與不可達特徵。
- 讓多數特徵可由同一次裝夾、同一方向加工。
- 非功能面不要指定過緊公差或過高表面光潔度。
- 對稱或重複特徵要考慮夾具定位與防呆。

### DFM 判斷表

| 設計特徵 | 製造風險 | 改善方式 |
|---|---|---|
| 內尖角 | 刀具無法形成零半徑角 | 加入圓角，半徑大於標準刀具半徑 |
| 深窄槽 | 刀具細長、易振動 | 放寬槽寬或改變結構 |
| 非標準孔徑 | 需特殊刀具 | 改用標準鑽頭、鉸刀或螺紋尺寸 |
| 雙側孔加工 | 需翻面，位置誤差累積 | 改成單側可加工 |
| 過緊公差 | 成本與檢驗負擔上升 | 只在功能面保留精度 |
| 薄壁件 | 夾持與切削力造成變形 | 加厚、加肋、改變加工順序或使用軟爪 |

## 研究所層級考題

### A. 觀念題

1. 說明創建與成形的差異，並各舉兩個加工例子。  
   參考方向：創建由相對運動決定包絡面；成形由刀具輪廓決定工件輪廓。

2. 為什麼車削長軸時容易產生錐度誤差？  
   參考方向：切削力造成工件撓曲、尾座不同心、刀具磨耗、熱變形。

3. 比較鑽孔、搪孔、鉸孔在孔加工中的功能差異。  
   參考方向：鑽孔建立孔，搪孔修正位置與圓度，鉸孔改善尺寸與表面。

4. 為什麼銑削比車削更容易出現週期性振動問題？  
   參考方向：多齒斷續切削、刀齒進出造成週期力、刀具跳動。

5. 說明順銑與逆銑的切屑厚度變化與適用條件。  
   參考方向：順銑由厚到薄、逆銑由薄到厚；順銑要求剛性與背隙控制。

6. 綜合加工機提高生產率的原因有哪些？  
   參考方向：一次裝夾、自動換刀、托盤、自動定位、減少基準轉換。

7. 為什麼拉削適合大量生產但不適合少量客製？  
   參考方向：拉刀昂貴且專用，但節拍短、尺寸一致性好。

8. 高速加工為什麼不能只靠提高主軸轉速？  
   參考方向：還需刀柄平衡、預讀控制、排屑、冷卻、刀路與機台剛性。

9. 理論表面粗糙度和實際表面粗糙度為何不同？  
   參考方向：實際加工還有積屑瘤、材料撕裂、振動、磨耗與熱變形。

10. 請提出三個能降低加工成本的產品設計策略。  
    參考方向：標準刀具、減少設定、放寬非功能公差、避免底切。

### B. 計算題

1. 外圓車削一支直徑 50 mm 的鋼棒，建議切削速度為 120 m/min，求主軸轉速。  
   解題方向：`N = 1000V/(piD)`，約 `764 rev/min`。

2. 車削長度 150 mm，進給 0.25 mm/rev，主軸轉速 600 rev/min，求加工時間。  
   解題方向：`T_m = L/(fN)`，約 `1.0 min`。

3. 鑽直徑 12 mm 的孔，進給 0.18 mm/rev，主軸轉速 900 rev/min，求 MRR。  
   解題方向：`MRR = (piD^2/4)fN`，約 `18,300 mm^3/min`。

4. 立銑刀 4 刃，主軸 3000 rev/min，每齒進給 0.04 mm/tooth，求工作台進給。  
   解題方向：`F = f_z z N`，答案 `480 mm/min`。

5. 面銑切寬 40 mm、切深 2 mm、進給 500 mm/min，求 MRR。  
   解題方向：`MRR = w d F`，答案 `40,000 mm^3/min`。

6. 車削進給 0.20 mm/rev，刀鼻半徑 0.8 mm，估算理論 `R_a`。  
   解題方向：`R_a ≈ f^2/(32r_n)`，約 `0.00156 mm = 1.56 micrometer`。

7. 某製程規格為 20.00 ± 0.03 mm，製程標準差為 0.006 mm，求 `C_p`。  
   解題方向：`C_p = 0.06/(6*0.006)`，約 `1.67`。

8. 已知刀具壽命式 `VT^0.25 = 300`，若切削速度從 150 m/min 提高到 200 m/min，刀具壽命比值為何？  
   解題方向：`T = (C/V)^(1/n)`，速度提高會使壽命大幅下降；`T_2/T_1 = (150/200)^4 ≈ 0.316`。

### C. 設計與製程規劃題

1. 一個軸類零件具有外圓、端面、中心孔、外螺紋與側向平面。請規劃傳統加工流程與銑車削中心流程，並比較設定次數。

2. 某零件要求內孔 `Ra 0.8 micrometer`、孔徑公差 ±0.01 mm。只用鑽孔是否合理？若不合理，請提出後續加工方案。

3. 一個設計含有 2 mm 寬、30 mm 深的窄槽。請從刀具剛性、排屑與加工成本角度提出改善建議。

4. 某零件所有表面都標註高表面光潔度與緊公差。請以 DFM 角度批判此設計，並提出標註修正原則。

5. 若大量生產具有內鍵槽的孔，請比較插削、銑削與拉削的成本、品質與產能。

## 影片觀看任務

看影片時不要只看機器動作，請記錄以下問題：

1. 主運動是工件旋轉、刀具旋轉，還是刀具往復？
2. 進給方向與加工表面幾何有什麼關係？
3. 工件如何定位與夾持？夾持方式可能造成什麼誤差？
4. 切屑是連續、斷續、短屑還是長屑？排屑是否順暢？
5. 加工表面可能受哪些因素影響？刀具、材料、振動、冷卻或進給？
6. 如果要量產，瓶頸會是切削時間、換刀、上下料、檢驗，還是刀具壽命？
